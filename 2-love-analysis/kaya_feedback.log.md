## Категория 1 — Картинка: композиция и уникальность (2 клиента)

### 1.1 — Генерировать сразу качественную уникальную карту по эталону, не «замазывать» текст поверх
> **Цитата (Мария):** «берешь эталон и генерируешь сразу хорошую красивую картинку, уникальных людей, уникальный символ, а не блевотню сверху размазываешь»

- **Категория:** картинка / качество
- **Что нужно:** брать эталон как макет, генерировать чистую карту (уникальные люди, уникальный символ), не накладывать текст поверх сырой генерации.
- **Внесено в SKILL.md:** частично (секция «Картинка»: макет как эталон, символ союза уникален). ⚠️ **GAP:** не было явного требования «уникальные люди/пара».

### 1.2 — Центральная пара уникальна и с внешностью из ДНК; 3 силы = пары; символ уникальный; низ разделён; тона цивилизаций
> **Цитата (Ирина):** «3 силы любви — там должна быть пара, пара по центру должна быть уникальна и обладать внешностью из ДНК, символ союза уникальный, внизу чёткое разделение где для пары, а где для меня. плюс можно добавить других тонов по описанию её цивилизаций»

- **Категория:** картинка / композиция
- **Что нужно:**
  - в каждой из 3 карточек «силы любви» — **пара**, а не одиночная фигура;
  - центральная пара — **уникальная**, с инопланетной внешностью по ведущим цивилизациям клиента (ДНК);
  - символ союза — **уникальный** (не копия прошлых);
  - низ — **чёткое разделение** «ДЛЯ МЕНЯ» / «ДЛЯ ПАРЫ»;
  - палитра — **дополнительные тона по цивилизациям** клиента.
- **Внесено в SKILL.md:** частично (был «символ союза уникален», «ДЛЯ ВАС | ДЛЯ ПАРЫ»). ⚠️ **GAP:** пара в каждой из 3 сил; уникальная центральная пара с ДНК-внешностью; тона по цивилизациям.

### 1.3 — Эталон картинки: если именованного нет — взять 3 последних, свести и сгенерировать уникальную
> **Цитаты (Ирина):** «найди эталон картинки любви и сделай по нему»; «найди эталон картинки любви, если его нет — возьми 3 последних к данному разбору, сделай общий вывод и сгенерируй ей уникальную картинку»
