## ФОРМАТ: ссылки ВИДИМЫЕ, боль развёрнутая

**ЗАПРЕЩЕНО** прятать ссылку в слово: `[Консультация](url)`. URL пишется **открытым текстом** после описания.

Каждая услуга = **5–7 предложений минимум:**
1. Боль (2–3 предложения): конкретный паттерн клиента ИЗ ЕГО КАРТЫ
2. Решение (2–3 предложения): что именно эта услуга делает с этой болью
3. URL отдельной строкой: `Подробности: https://...`

## Шаблоны

### 1. Книга «Активация Внеземной ДНК»

Назвать КОНКРЕТНЫЕ звёзды/цивилизации клиента с указанием планет + написать ЗАЧЕМ о них читать. Только данные из CSV/текста.

```
📚 У вас [звезда 1] на [планете], [звезда 2] на [планете] и [звезда 3] на [планете] — [N] линий, которые определяют ваш способ [конкретное из текста]. Как активировать каждую из этих линий в [теме разбора] — практики и ритуалы описаны в книге «Активация Внеземной ДНК»: https://intergalactic-astrology.com/book/
```

**ЗАПРЕЩЕНО:** общие фразы «в книге описаны все цивилизации», выдумывать соединения.

### 2. Тотальная консультация по любви

Описать КОНКРЕТНЫЙ паттерн/сложность клиента в паре + что разбирается за одну встречу.

```
[Описание паттерна: «накопил → взорвался», «идеализация → разочарование», «свобода vs близость»]. Именно этот паттерн разбирается на тотальной консультации по любви: за одну глубокую встречу [конкретный результат для этого клиента]. Подробности: https://intergalactic-astrology.com/services.html#total-consultation
```

### 3. Годовой прогноз

Связать с конкретной темой (8-й дом, тело, память) + АКЦЕНТ: **когда и как действовать, как себя сохранить**.

```
[Описание проблемы: тело хранит боль, старые паттерны мешают новому]. В годовом прогнозе — не просто «что произойдёт», а конкретно: когда и как действовать, чтобы не сломать то, что строится; как сохранить себя в период давления; в какие месяцы [конкретное], а в какие — дать себе паузу без вины. Подробности: https://intergalactic-astrology.com/services.html#year-forecast
```

**КЛЮЧЕВОЕ:** годовой прогноз = что происходит + как себя сохранить + когда действовать. НЕ «когда откроется окно».

