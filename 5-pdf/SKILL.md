# Подготовка PDF

## INPUT-гейт

- [ ] `<Имя>_<DDMMYYYY>_миссия.md` существует и прошёл валидацию (3-validation OK)
- [ ] `summary.md` существует
- [ ] `Generated_image.png` существует

## Идемпотентность

Если PDF уже существует и >500KB — шаг пропускается. Принудительная перегенерация — только по прямому запросу Дарьи.

## Алгоритм

### 1. Проверка структуры MD

Скрипт `generate_pdf.py` разделяет текст по H2-заголовкам. Если заголовки нарушены — PDF сломан.

**Обязательные заголовки:**
- [ ] H2 содержащий «СТРУКТУРА ДНК» (с emoji 📋 или без)
- [ ] H2 содержащий «АНАЛИЗ МИССИИ»
- [ ] «СТРУКТУРА ДНК» идёт ПЕРЕД «АНАЛИЗ МИССИИ»
- [ ] Нет лишних H2 между ними
- [ ] «Как я работаю» и WhatsApp CTA — в конце

Если структура нарушена → исправить MD перед конвертацией.

### 2. Конвертация

```powershell
$env:PYTHONIOENCODING="utf-8"
python ".cursor/skills/5-pdf/generate_pdf.py" -i "<папка_клиента>\<имя>_миссия.md"
```

Скрипт ищет относительные пути внутри `D:\DariaGalactic\Профайлы клиентов\`. Для другого расположения можно задать `CLIENT_PROFILES_DIR`.

### 3. Верификация данных клиента

Сверить имя, дату рождения, место из PDF с Google Sheet. Если расхождение — СТОП.

### 4. Проверка результата

- [ ] PDF создан
- [ ] Размер >500KB (если меньше — сломан)
- [ ] В stdout все 5 шагов (MD→HTML, разделение, стилизация, изображения, HTML→PDF)

## OUTPUT-гейт

- [ ] `<Имя>_<DDMMYYYY>_миссия.pdf` существует, >500KB
- [ ] Данные клиента в PDF совпадают с Sheet

## Типичные ошибки

| Симптом | Причина | Решение |
|---|---|---|
| Весь текст одного стиля | Заголовки не содержат «СТРУКТУРА ДНК» | Переименовать H2 |
| PDF <500 KB | Chrome не дождался шрифтов | Повторить |
| Таблица обрезана | Много столбцов | Убрать лишние |
| Пустые страницы | Лишние `---` перед H2 | Убрать hr |

## Зависимости

- Python 3, pandoc (в PATH), Google Chrome (headless)
- Скрипт: `.cursor/skills/5-pdf/generate_pdf.py`
