# Выкачка карт клиентов

## Что делает

Скачивает папки оплативших клиентов из общей папки «Разборы» на Google Drive в единственную рабочую папку `D:\DariaGalactic\Профайлы клиентов\`. В каждой папке лежит CSV с натальной картой (создан Worker'ом после оплаты).

В Cursor эта же папка видна через символическую ссылку `DariaGalactic/Профайлы клиентов/`, но программы должны писать напрямую на диск D.

## Скрипт

```
.cursor/skills/1-download/pull_client.py
```

## Три режима запуска

### 1. Батч (ежедневный синк)

```powershell
python ".cursor/skills/1-download/pull_client.py" --all
```

Перечисляет всё содержимое общей папки «Разборы» в Drive, для каждой подпапки проверяет наличие CSV и докачивает локально. Уже скачанные пропускает (idempotent).

### 2. Точечный (один клиент)

```powershell
python ".cursor/skills/1-download/pull_client.py" <email_клиента>
```

Если у email две оплаты — указать конкретный контракт:
```powershell
python ".cursor/skills/1-download/pull_client.py" <email> --contract <contractId>
```

### 3. Генерация CSV (если Worker не создал)

```powershell
python ".cursor/skills/1-download/pull_client.py" --regen-csv-for <email>
```

Обращается к Worker для генерации CSV. Если Worker не может — эскалация к Дарье.

## Формат папки клиента

**На GDrive (создаёт Worker после оплаты):**
```
Разборы/<Имя>_<contract12>_<YYYYMMDD>/
└── karta_<contract12>.csv
```

**Локально (после pull_client.py):**
```
D:\DariaGalactic\Профайлы клиентов\<Имя>_<contract12>_<YYYYMMDD>\
└── karta_<contract12>.csv
```

Где:
- `<Имя>` — имя клиента из Google Sheet
- `<contract12>` — последние 12 символов contractId
- `<YYYYMMDD>` — дата покупки

## OUTPUT-гейт (проверка после скачивания)

- [ ] Папка клиента создана в `D:\DariaGalactic\Профайлы клиентов\`
- [ ] `karta_*.csv` существует, >1KB
- [ ] CSV содержит столбцы: Planet, Star, Orb, House, Aspect

## Авторизация

- OAuth-токен: `DariaGalactic/config/gdrive_token.json`
- Если `DariaGalactic/config` пустой или удалён, восстановить runtime-креды из приватного репозитория `https://github.com/ResearcherryAI/Intergalacticcreds.git`: `.env`, `client_secret_*.json`, `gdrive_token.json`, `cabinet_sheet_token.json`.
- Аккаунт: `interviewkotilev@gmail.com`
- Если 404 при list/download → удалить `gdrive_token.json`, запустить снова, в браузере выбрать правильный аккаунт

## Обработка ошибок

| Ошибка | Причина | Решение |
|---|---|---|
| 404 на list/download | Токен от другого аккаунта | Удалить `gdrive_token.json`, перезапустить |
| Пустая папка (нет CSV) | Worker ещё не создал карту | `--regen-csv-for <email>` или подождать |
| `FileNotFoundError: config/` | Нет секретов | Восстановить из `DariaGalactic/config/secrets.local.md` |

## ⛔ ГЕЙТ: Запрет на удаление с GDrive и локально

- **ЗАПРЕЩЕНО** удалять файлы с `gdrive:DariaGalactic/Клиенты/` — клиентские кабинеты ссылаются на них
- **ЗАПРЕЩЕНО** использовать `rclone sync` — только `rclone copy`
- **ЗАПРЕЩЕНО** удалять локальные папки клиентов на D:\ без явного указания Дарьи
- Скачивание всегда идёт ТОЛЬКО на `D:\DariaGalactic\Профайлы клиентов\Купившие разбор\`

## ⛔ ГЕЙТ: Фильтр по статусу (БЛОКИРУЮЩИЙ)

- **ЗАПРЕЩЕНО** скачивать все папки с GDrive (`rclone copy` всей директории `Разборы/`). Это приводит к скачиванию 60+ папок вместо нужных 5-10
- Перед ЛЮБЫМ скачиванием — обязательно прочитать Google Sheet и определить список клиентов со статусом **«В разборе у Дарьи»**
- Режим `--all` скачивает ТОЛЬКО клиентов, у которых:
  1. Статус в Sheet = «В разборе у Дарьи»
  2. Папка с их contract12 **ещё не существует** локально в `D:\DariaGalactic\Профайлы клиентов\Купившие разбор\`
- Клиенты, которые уже скачаны (папка есть на D:\), пропускаются — даже если статус всё ещё «В разборе»
- Если нужно скачать конкретного клиента — использовать точечный режим с email
- **Результат скачивания** — вывести в чат: «Новых для скачивания: N, уже скачаны: M». Если N > 15 — СТОП, что-то пошло не так

**Причина правила:** агент ранее скачал все 42 папки с GDrive вместо 5 нужных (см. `pipeline_errors.md`, обратная связь Дарьи 2026-05-14)
