# Выкачка карт клиентов

## Что делает

Скачивает папки оплативших клиентов из общей папки «Разборы» на Google Drive в единственную рабочую папку `D:\DariaGalactic\Профайлы клиентов\`. В каждой папке лежит:
- `karta_<short>.csv` — натальная карта (cabinet-v2 после оплаты, Sheet G = `Оплата получена`)
- `<Имя>_<ddmmyyyy>_миссия.md` — AI-разбор (`intergalactic-ai-agent` → n8n R22, ~5–15 мин, Sheet G = `Разбор АИ готов (на проверке у Кайи)`)

В Cursor эта же папка видна через символическую ссылку `DariaGalactic/Профайлы клиентов/`, но программы должны писать напрямую на диск D.

## ⚠️ ВАЖНО: новый флоу (22.05.2026)

`pull_client.py` теперь скачивает **ВСЁ** содержимое папки клиента, включая `.md` от агента. В выводе на каждую папку печатается маркер:
- `[AI-разбор готов]` — `.md` от агента есть, можно открывать локально и проверять
- (без маркера) — пока только CSV, n8n ещё генерит или не стартовал

Кайя не пишет разбор с нуля — она **проверяет и точечно дорабатывает** AI-выход (`2-analysis/SKILL.md` шаг «Доработка AI-разбора»).

## Скрипт

```
.cursor/skills/1-download/pull_client.py
```

## Режимы запуска

### 1. Батч (ежедневный синк)

```powershell
python ".cursor/skills/1-download/pull_client.py" --all
```

Перечисляет всё содержимое общей папки «Разборы» в Drive, для каждой подпапки проверяет наличие CSV и докачивает локально. Уже скачанные пропускает (idempotent).

### 2. Точечный (один клиент)

```powershell
python ".cursor/skills/1-download/pull_client.py" <email_клиента>
```

Если у email две оплаты — указать конкретный контракт:
```powershell
python ".cursor/skills/1-download/pull_client.py" <email> --contract <contractId>
```

Если у email два разных продукта (mission + money_dna) — указать продукт:
```powershell
python ".cursor/skills/1-download/pull_client.py" <email> --product mission
python ".cursor/skills/1-download/pull_client.py" <email> --product money_dna
```

### Флаг --force (полная перекачка)

Добавь `--force` к любой команде, чтобы перекачать ВСЁ содержимое папки заново, даже если файлы уже есть локально:

```powershell
python ".cursor/skills/1-download/pull_client.py" --all --force
python ".cursor/skills/1-download/pull_client.py" <email> --force
```

Без `--force` — скачивается только то, чего нет (по умолчанию).
С `--force` — перезаписываются все файлы актуальными версиями из Google Drive.

### 3. Генерация CSV (если Worker не создал)

```powershell
python ".cursor/skills/1-download/pull_client.py" --regen-csv-for <email>
```

Обращается к Worker для генерации CSV. Если Worker не может — эскалация к Дарье.

## Формат папки клиента

**На GDrive (`Разборы/`):**
```
Разборы/<Имя>_<contract12>_<YYYYMMDD>/
├── karta_<contract12>.csv               ← cabinet-v2
└── <Имя>_<ddmmyyyy>_миссия.md           ← intergalactic-ai-agent (n8n R22)
```

**Локально (после pull_client.py):**
```
D:\DariaGalactic\Профайлы клиентов\Купившие разбор\<Имя>_<contract12>_<YYYYMMDD>\
├── karta_<contract12>.csv
└── <Имя>_<ddmmyyyy>_миссия.md           ← AI-разбор для проверки + доработки
```

Где:
- `<Имя>` — имя клиента из Google Sheet
- `<contract12>` — последние 12 символов contractId
- `<YYYYMMDD>` — дата покупки

## OUTPUT-гейт (проверка после скачивания)

- [ ] Папка клиента создана в `D:\DariaGalactic\Профайлы клиентов\Купившие разбор\`
- [ ] `karta_*.csv` существует, >1KB
- [ ] CSV содержит столбцы: Planet, Star, Orb, House, Aspect
- [ ] `<Имя>_*_миссия.md` существует (маркер `[AI-разбор готов]` в выводе скрипта) — для новых клиентов (после 22.05.2026); legacy могут быть без .md, тогда писать вручную по 2-analysis

## ⚠️ Статусы Sheet (2-stage flow)

| Статус (колонка G) | Кто ставит | Что делать |
|---|---|---|
| `Оплата получена` | cabinet | ждать AI-разбор (1-7 мин), повторно pull |
| `Ожидает карту от клиента` | cabinet (split-flow) | ждать карту от клиента |
| `Разбор АИ готов (на проверке у Кайи)` | agent | **pull + проверка по 2-analysis + бенчмаркинг (3-validation)** |
| `Готов · выдан клиенту` | deliver_mission.py | завершено |
| `В разборе у Кайи Каэн` | legacy | legacy до 22.05.2026, продолжать как раньше |

- Аккаунт: `interviewkotilev@gmail.com`

## Обработка ошибок

| Ошибка | Причина | Решение |
|---|---|---|
| 404 на list/download | Токен от другого аккаунта | Удалить `gdrive_token.json`, перезапустить |
| Пустая папка (нет CSV) | Worker ещё не создал карту | `--regen-csv-for <email>` или подождать |
| `FileNotFoundError: config/` | Нет секретов | Восстановить из `DariaGalactic/config/secrets.local.md` |

## ⛔ ГЕЙТ: Запрет на удаление с GDrive и локально

- **ЗАПРЕЩЕНО** удалять файлы с `gdrive:DariaGalactic/Клиенты/` — клиентские кабинеты ссылаются на них
- **ЗАПРЕЩЕНО** использовать `rclone sync` — только `rclone copy`
- **ЗАПРЕЩЕНО** удалять локальные папки клиентов на D:\ без явного указания Дарьи
- Скачивание всегда идёт ТОЛЬКО на `D:\DariaGalactic\Профайлы клиентов\Купившие разбор\`

## ⛔ ГЕЙТ: Фильтр по статусу (БЛОКИРУЮЩИЙ)

- **ЗАПРЕЩЕНО** скачивать все папки с GDrive (`rclone copy` всей директории `Разборы/`). Это приводит к скачиванию 60+ папок вместо нужных 5-10
- Перед ЛЮБЫМ скачиванием — обязательно прочитать Google Sheet и определить список клиентов со статусами **«Разбор АИ готов (на проверке у Кайи)»** ИЛИ **«В разборе у Кайи Каэн»** (legacy)
- Режим `--all` скачивает ТОЛЬКО клиентов, у которых:
  1. Статус в Sheet ∈ {«Разбор АИ готов (на проверке у Кайи)», «В разборе у Кайи Каэн»}
  2. Папка с их contract12 **ещё не существует локально** ИЛИ существует, но без `*_миссия.md` (агент добавил после первого pull)
- Клиенты, у которых уже всё локально (CSV + AI-разбор), пропускаются
- Если нужно скачать конкретного клиента — использовать точечный режим с email
- **Результат скачивания** — вывести в чат: «Новых для скачивания: N, уже скачаны: M, с готовым AI-разбором: K». Если N > 15 — СТОП, что-то пошло не так

**Причина правила:** агент ранее скачал все 42 папки с GDrive вместо 5 нужных (см. `pipeline_errors.md`, обратная связь Дарьи 2026-05-14)

## 📊 Output summary (ОБЯЗАТЕЛЬНО показывать в чат после --all)

После каждого батча `pull_client.py --all` оркестратор печатает в чат сводку:

```
📊 СВОДКА СКАЧИВАНИЯ:
- 🤖 С готовым AI-разбором (.md от агента): K
- 📥 Только CSV (агент ещё не отработал): N
- 🕰️ Legacy (статус «В разборе у Кайи Каэн», без AI .md): L
- ✅ Уже скачаны (skip): M
- ❌ Ошибки скачивания: E

К работе сейчас: K + L = T клиентов
```

**Действия по результату:**
- `K > 0` → начинать AI-Review (доработка v2) для каждого из K
- `N > 0` → подождать 5-10 мин, повторить pull, агент должен догнать
- `L > 0` → полный анализ с нуля по `2-analysis/SKILL.md`
- `E > 0` → разобраться с ошибками до продолжения
