# Справочник: звезда / цивилизация → денежный архетип

Используется агентом при написании разбора ДНК денег. Когда у планеты есть соединение (☌) со звездой — этот справочник определяет СПОСОБ МАТЕРИАЛИЗАЦИИ и конкретные профессии.

**Приоритет:** справочник дополняет (не заменяет) описание цивилизации из `library_compact.json` и чанков книги. Книга описывает цивилизацию для миссии; этот справочник — для денег.

## ПРАВИЛО ИСПОЛЬЗОВАНИЯ

1. Найти звезду в справочнике → получить денежный архетип и профессии
2. Наложить на ДОМ планеты (колонка «Особенности») → уточнить контекст
3. Наложить качества планеты (из `money_planet_sign_professions.md`) → дополнить
4. Описать СПОСОБ МАТЕРИАЛИЗАЦИИ = архетип + профессии + дом + качества планеты
5. Если звезды нет в справочнике → использовать описание из `library_compact.json` и перевести в денежный контекст через дом

**Пример:** Луна ☌ Денебола (1.81°) в 11-м доме → из справочника: «нестандартный руководитель, руководитель проекта в непривычном формате, лидер нестандартного сообщества». Из дома: «11-й = прибыль, сеть, сообщества». Результат: «СПОСОБ МАТЕРИАЛИЗАЦИИ: НЕСТАНДАРТНОЕ РУКОВОДСТВО ГРУППОЙ. Деньги приходят, когда вы занимаете руководящую позицию — но не классическую, а авторскую: руководитель сообщества с нестандартным форматом, глава проекта, который делает по-своему. Конкретные форматы: директор онлайн-школы с уникальной методологией, руководитель клуба, глава творческого объединения.»
