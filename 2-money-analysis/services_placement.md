## ФОРМАТ ССЫЛКИ — ТОЛЬКО ВИДИМЫЙ URL

**ЗАПРЕЩЕНО** использовать markdown-гиперссылки `[текст](url)`. Клиент должен видеть адрес.

**Правильно:**
```
Тотальная консультация: https://intergalactic-astrology.com/services.html#consultation-508
```

**Неправильно:**
```
[Тотальная консультация](https://intergalactic-astrology.com/services.html#consultation-508)
Ознакомиться с услугой подробнее можно по ссылке: [...]
```

## ПРИНЦИП: боль → решение → ссылка (объёмно, просто, по-человечески)

Каждая услуга — это **5–7 предложений минимум**, написанных простым языком, как в разговоре:

1. **Боль** (2–3 предложения): конкретная ситуация клиента ИЗ ЕГО КАРТЫ — что мешает, где застрял, что чувствует. Не абстрактно.
2. **Решение** (2–3 предложения): что именно эта услуга делает с этой болью — простым языком, без канцелярита.
3. **Ссылка**: название услуги + URL видимым текстом, отдельной строкой.

**Запрещённые обороты:**
- «Ознакомиться с услугой подробнее можно по ссылке»
- «Если интересно»
- «Существует возможность»
- «Рекомендуем воспользоваться»
- Любой канцелярит

**Разрешённый тон:**
- Утвердительный, тёплый, прямой
- Как будто Дарья говорит клиенту лично
- Простые слова, короткие предложения
- Конкретика из карты (планеты, дома, звёзды, тени)

## АБСОЛЮТНЫЕ ПРАВИЛА

1. **Боль из карты = ОБЯЗАТЕЛЬНО.** Каждая вставка начинается с конкретной ситуации клиента (планета + дом + звезда + что мешает). Без этого — ЗАПРЕЩЕНО вставлять ссылку.

2. **Каждая услуга — ровно 1 раз в тексте.** Повтор = навязчивость.

3. **Без сроков.** Не писать «за 6 месяцев», «за 90 дней», «через полгода».

4. **Без давления.** Тон утвердительный, но не директивный. НЕ: «вам необходимо», «срочно», «обязательно».

5. **Количество в одном разборе:** 4–5 из каталога. **Обязательные всегда:** Книга + **Разбор миссии** + Тотальная консультация + Сопровождение. Годовой прогноз — если есть окна/тайминг в карте (обычно да). Миссия больше НЕ «опциональная» (волна 09–10.07.2026: отсутствовала у Екатерины, Дианы и Артёма).

6. **Книга — не раньше 3-го раздела** и только после перечисления 2+ конкретных соединений.

7. **Сопровождение — всегда последний раздел** (перед копирайтом). Включает ссылку на WhatsApp.

8. **Формат ссылки — ТОЛЬКО видимый URL.** Markdown-гиперссылки `[текст](url)` ЗАПРЕЩЕНЫ.

9. **Объём описания — минимум 5 предложений** на каждую услугу. Одна строка с URL = нарушение.

10. **Миссия и Книга — в РАЗНЫХ разделах.** Разная логика привязки.

11. **Услуги НЕ стоят подряд.** Между двумя CTA — минимум **один полный H2-раздел** без сервисных URL. Между **Тотальной и Сопровождением** — минимум **два** полных H2 (канон: Практики + Что мешает; «5 сил» не считается достаточным единственным буфером). Запрещены пары в одном разделе: Тотальная+Годовой, Тотальная+Миссия, Книга+Миссия, любые две ссылки через абзац без «мяса» карты (Диана, 09.07.2026; дистанция Тотальная↔Сопровождение — Екатерина 29111994, 12.07.2026).

12. **Тотальная консультация — якорь «после 11 СФЕР».** Всегда там; боль = «11 дорог без приоритета» + узел этой карты. Не в «Что мешает», не у Сопровождения.

## ЖЁСТКАЯ КАРТА РАССТАНОВКИ (не импровизировать)

Порядок CTA в ДНК денег **фиксирован**. Не двигать «по вкусу».

| # | Услуга | Якорь-раздел | Минимальная дистанция |
|---|--------|--------------|------------------------|
| 1 | Книга | после 2+ цивилизаций, не раньше §3 (часто §6 Раху/Кету) | — |
| 2 | Миссия | другой H2, чем Книга (часто «Особые показатели» / Солнце+Плутон) | ≥1 полный H2 между Книгой и Миссией (**соседние § запрещены**) |
| 3 | Годовой прогноз | **ВОЗРАСТЫ ФИНАНСОВОГО ПРОРЫВА** | не в одном разделе с Тотальной |
| 4 | Тотальная | **хвост «11 СФЕР»** | ≥2 полных H2 до Сопровождения |
| 5 | Сопровождение | последний H2 перед копирайтом + WhatsApp | всегда последний |

**Типовой хвост файла (не ломать):**  
`… → Возрасты (+Годовой) → 11 сфер (+Тотальная) → Практики → Что мешает (без URL) → 5 сил → Сопровождение`

**Чеклист перед сдачей:** выписать 5 URL по порядку появления в тексте — сверить с таблицей выше. Если порядок другой или дистанция меньше — HARD FAIL, переставить.

## ЗАПРЕЩЕНО

- Markdown-гиперссылки `[текст](url)` — только видимый URL
- «Ознакомиться с услугой подробнее можно по ссылке» и любой канцелярит
- «Если интересно», «если хотите узнать больше»
- Вставлять ссылку без 5+ предложений описания боли и решения
- Писать «вам необходимо», «обязательно воспользуйтесь», «рекомендуем»
- Указывать цены услуг
- Указывать сроки работы
- Ставить 2 ссылки в одном абзаце
- Размещать Книгу в 1-м или 2-м разделе
- Размещать Сопровождение в середине текста
- Ставить Книгу и Миссию в одном разделе
- Ставить Тотальную и Годовой прогноз в одном разделе
- Ставить Тотальную в «ЧТО МОЖЕТ МЕШАТЬ» / перед Сопровождением / после «5 сил»
- Ставить Книгу и Миссию в соседних H2 (между ними должен быть ≥1 полный раздел без URL)
- Ставить две услуги подряд / в соседних абзацах без смыслового блока между ними
- Импровизировать якоря услуг вне таблицы «Жёсткая карта расстановки»
- Пропускать CTA «Разбор миссии»
- Ссылку на Энергодуш (услуга убрана из каталога)
- Ссылку на about.html (старые URL) — только services.html / analyses.html / book
- Писать абстрактно без конкретных соединений из карты
- Годовой прогноз / тотальную без боли именно этого клиента
