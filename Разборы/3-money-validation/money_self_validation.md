## БЛОК 0 — ТОП самых частых ошибок за последнее время (проверять ПЕРВЫМ)

Это «горячий список» — ошибки, которые повторялись чаще всего в последних разборах (Лариса, Кайя, Зарема, Александр, Ксения). Эталон, на котором показано, КАК надо: `Лариса_16081985_деньги.md`. Сначала прогнать гейт-валидатор, потом пройти список глазами.

### 0.1. Сначала автоматический гейт (ловит ~20 ошибок)

```
python .cursor/skills/2-money-analysis/money_validate.py "<путь к *_деньги.md>"
```
Пока есть хоть один `[FAIL]` — показывать ЗАПРЕЩЕНО. Валидатор сам держит: порядок разделов, тени перед Сопровождением, ровно 11 сфер + «Через год», ровно 2 практики, 5 ссылок, цивилизации A/B/C, отсутствие 3-го лица / жаргона / латиницы, **+ A–G**: (A) диспозиторы Раху/Кету с действием, (B) флагман-профессия, (C) 3 пласта сфер, (D) аттрактор → тень «без фильтра», (E) достоинство Марса/Луны в Раке, (F) нет урока-джйотиш, (G) перегруз наставничеством; **+ J–W**: (J/P) выдумка/имена звёзд из CSV, (K) расчёты, (L) рассуждения агента/ранжирование сил, (M) 1 услуга/раздел, (N) копипаст «курсы», (O) цивилизация на Асценденте, (Q) соединения 1-го дома, (R) книга у цивилизаций, **(S)** орб=CSV, **(T)** своё соединение раздела раскрыто как цивилизация, **(U)** Энергодуш по смыслу (не «прибит» к Сатурну), **(V)** конкретные профессии в т.ч. в 11 сферах, **(W)** стеллиумы раскрыты как взаимосвязь.

### 0.2. Потом глазами — то, что регулярка НЕ ловит (10 пунктов)

1. **Качества знака + достоинство (самая частая ошибка).** Каждая планета описана через РЕАЛЬНЫЙ знак и достоинство, а не «идеальную» версию. Марс в Раке = падение (забота, защита, продажа безопасностью — НЕ «дожим/давление»). Луна в Раке = свой знак, чутьё/интуиция (НЕ «учится считать и удерживать» — это Дева/Козерог). Проверка: для КАЖДОЙ планеты спросить «совпадает ли смысл со знаком и достоинством?».
2. **Дом = ВСЕ каналы, не один.** Дом не сведён к одному смыслу. 10-й = публичность/блог + найм/руководитель в структуре/госсекторе + своя система. Веер дорог, мы их объединяем, а не выкидываем.
3. **Стеллиум — каждая планета отдельно + синтез связи (проверка W).** Если 2+ планеты в одном доме/знаке — расписана КАЖДАЯ по качествам знака и накшатры в денежном ключе, И обязателен абзац-синтез: как они влияют друг на друга и работают ВМЕСТЕ на деньги (не «вся энергия туда» и не по одиночке без связи).
4. **Помощник = достоинство управителя 7-го.** Помощник выведен из реального достоинства планеты. Управитель в падении → не «сильная функция». Марс в Раке → операционный/финансовый тыл (Дева/Козерог/Телец), НЕ «жёсткий переговорщик».
5. **Диспозиторы Раху/Кету — практика, а не ярлык.** По Раху — «куда пойти, чтобы пришли клиенты/партнёры» (через дом диспозитора). По Кету — «что сделать, чтобы талант открылся и начал приносить деньги». Не просто «диспозитор — Марс».
6. **Профессии: конкретно + флагман + уникальность + во всех пластах (проверка V).** 2–3 конкретных примера в каждой сфере; одна объединяющая флагман-профессия перед списком; формулировки НЕ «как у всех» (сверить с 2–3 последними картами); не сводить большинство сфер к наставничеству (только где есть показатель — Сатурн/Юпитер/«учитель пути»). Конкретика — НЕ только в эзотерических сферах: в материальных (3) и масштабных (4) тоже реальные названия профессий, а не «образно».
7. **Накшатра/цивилизация — всегда через дом.** Формула: [накшатра/цивилизация] + [дом] = [конкретный денежный канал]. Никаких абстракций «в воздухе».
8. **Без урока джйотиш.** Если у показателя нет соединения — дать денежный смысл накшатры (формы дохода, профессии), а не «управитель/божество/символ/пады».
9. **ТОП-3 = только соединения (☌).** Ни одна цивилизация ТОП-3 не попала туда через аспект (△ ⚹ ☍ □). Аспекты — в «Особые показатели богатства».
10. **Сверка с CSV.** Дом/знак/накшатра каждой планеты совпадают с `karta_*.csv`. Куспы (29°50'–0°20') — отмечено влияние соседнего знака/дома.

## БЛОК 1 — Управление знаками (ЗАКРЫТЫЙ СПИСОК)

Управители знаков — ТОЛЬКО классическая ведическая сетка:

| Знак | Управитель | Знак | Управитель |
|------|-----------|------|-----------|
| Овен | Марс | Весы | Венера |
| Телец | Венера | Скорпион | Марс |
| Близнецы | Меркурий | Стрелец | Юпитер |
| Рак | Луна | Козерог | Сатурн |
| Лев | Солнце | Водолей | **Сатурн** |

**ЗАПРЕЩЕНО приписывать управление:**
- Раху / Кету — НЕ управляют никаким знаком
- Уран — НЕ управляет Водолеем (только Сатурн)
- Нептун — НЕ управляет Рыбами (только Юпитер)
- Плутон — НЕ управляет Скорпионом (только Марс)

Проверка: Ctrl+F «управ» в тексте → каждое упоминание управления сверить с таблицей.

## БЛОК 2 — Плутон, Венера, накшатры домов

**Плутон** — не карака, не ТОП-3. ЗАПРЕЩЕНО: «главный денежный код», «первичный финансовый канал». Если Плутон в **H2/H11** — обязателен абзац: планета + накшатра + влияние на ресурс + аспекты к звёздам из CSV.

**Венера** — не карака богатства; если во **2-м/11-м** — описать влияние на ресурс.

**Накшатра дома** без планеты — НЕ описывать (исключение: накшатра **Асцендента**). Правильно: «Плутон во 2-м, Хаста/3», не «Хаста во 2-м доме».

Проверка: Ctrl+F «Хаста» / «накшатра» + номер дома → всегда есть имя планеты (или это Асцендент).

## БЛОК 3 — Обязательный формат описания цивилизации

Для КАЖДОЙ из 3 цивилизаций в ТОП-3 обязательны три блока:

**A) «Кто эти существа»** — 4–6 предложений:
- рост, телосложение, кожа, глаза, волосы
- архетип (кто они по сути)
- их главный дар / принцип

**B) «СПОСОБ МАТЕРИАЛИЗАЦИИ: [НАЗВАНИЕ КАПСОМ]»** — 3–4 предложения:
- КАК именно эта цивилизация конвертирует энергию в деньги
- Через какие форматы это работает (менторство, система, красота и т.п.)
- Почему клиенты платят (что получают)

**C) «Как [цивилизация] работает у вас в деньгах»** — 3–5 предложений:
- Привязка к конкретному дому, планете, накшатре клиента
- Что это значит практически для его заработка

Без всех трёх блоков у каждой цивилизации — файл не готов.

## БЛОК 6 — Уникальность «11 сфер максимальных денег»

**Обязательная структура: 3 + 3 + 4 + 1 = 11**
- «Эзотерические / духовно-проводнические» — ровно **3** шт.
- «Конкретные материальные» — ровно **3** шт.
- «Масштабный бизнес» — ровно **4** шт.
- «Интеграционная» — ровно **1** шт.

Каждый из 11 пунктов ОБЯЗАН содержать:
- Привязку к КОНКРЕТНОМУ положению из карты этого клиента (планета + дом + накшатра или звезда)
- Уникальное название сферы (не generic «коучинг», «консалтинг», «инвестиции», «недвижимость»)
- Описание «через год» — конкретный, измеримый результат

**Перед завершением:** сравнить 11 сфер с последними 2–3 написанными клиентами. Если >3 пунктов совпадают по формулировкам или названиям сфер — переписать уникально.

**Минимум на каждый пункт:** 4–5 предложений (не 1–2). Описать: что это за формат, кто платит, как выглядит работа, какой чек/объём. «Через год» — конкретный измеримый результат.

**Денежная формула** — без астрологических терминов. Ни «Центавр», ни «Шравана», ни «андромедянский». Только бизнес-язык: что делаю → для кого → в каком формате → почему платят.

**Книга** — описывать как отдельную сферу в середине 11 сфер. НЕ размещать ссылку на книгу «Активация ДНК» рядом с блоком «Сопровождение» в конце файла.

Запрещённые generic-формулировки:
- «коучинг и консультирование» (слишком размыто)
- «инвестиции в недвижимость» (если нет прямого указания из карты)
- «онлайн-школа» (если не привязано к конкретной планете + дому)

## БЛОК 8 — Сверка с CSV (дома и знаки планет)

ПЕРЕД финализацией текста:
1. Открыть `karta_*.csv` клиента
2. Для КАЖДОЙ упомянутой планеты сверить:
   - Дом в тексте = дом в CSV (колонка 4)
   - Знак в тексте = знак, определяемый по градусу (колонка 2)
   - Накшатра в тексте = накшатра в CSV (колонка 3)
3. Если планета на куспе (29°50'–0°20'):
   - Записать основное положение **как в CSV** (не переносить)
   - Добавить 1–2 предложения: «на границе с [соседний знак/дом], что добавляет влияние: [краткое описание]»

**Любое расхождение дом/знак между текстом и CSV = критическая ошибка.**
