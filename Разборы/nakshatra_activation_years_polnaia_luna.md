## Как читать таблицу

Числа после названия накшатры — это **возраст в годах жизни** (1-й год после рождения, 2-й год и т. д.), когда по этой методике связанная с рождётной позицией энергия накшатры «активируется» с особой яркостью.

**Перевод в календарный год:** `календарный год ≈ год рождения + возраст из таблицы` (для точных дат окно уточняется относительно дня рождения).

В оригинале для накшатры **Шатабхиша** указано `28/29` — в JSON учтены **оба** возраста (28 и 29) как соседние окна.

## Применение в денежном разборе

При анализе **ДНК денег / финансовых пиков** для клиента брать накшатру из карты у:

1. **Юпитера** (ключевой показатель дханы по джйотиш);
2. **каждой планеты во 2-м доме целых знаков** (ресурс, голос цены);
3. **каждой планете в 11-м доме целых знаков** (прибыль, рост доходов);
4. **управителя 2-го дома** (Lord of 2nd);
5. **управителя 11-го дома** (Lord of 11th).

Для каждого такого объекта: найти накшатру в CSV (`Накшатра/Пада`) → название без пады совпадает со строками ниже → выписать **возрасты активации** и перевести их в календарные годы клиента как **особо значимые периоды внимания к деньгам и возможностям роста**.
