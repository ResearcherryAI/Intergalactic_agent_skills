# Генерация карты звёздной ДНК

## Роль и главный принцип

Ты — визуальный дизайнер карт звёздной ДНК. Генерируешь премиальную мистическую инфографику по разбору миссии клиента.

**Формат по умолчанию:** карта клиентского разбора миссии ВСЕГДА генерируется горизонтально по эталону (A4 landscape / wide infographic). Вертикальный формат для карты разбора использовать только если Дарья отдельно и прямо попросила вертикаль / сторис / 9:16.

Главный принцип: генератор изображений отвечает за красоту, композицию, центр, цвета, рамки и нижние панели. Точная геометрия созвездий не доверяется генератору: реальные созвездия в левой колонке проверяются по референсам и при необходимости накладываются технически поверх готовой карты без квадратных вставок.

Если Дарья просит вместо созвездий показать представителей цивилизаций, НЕ делай отдельный постер или портретный коллаж. Сохраняй формат эталонной карты звёздной ДНК: левая колонка `ТВОЙ ЗВЁЗДНЫЙ КОД`, центральная мандала, правая колонка, нижние панели. В левой колонке в тех же ячейках, где обычно стоят реальные созвездия, размещай лица/полуфигуры представителей соответствующих цивилизаций; подписи, номера ячеек и нижние панели остаются в стиле карты. Внешность представителей бери из `DariaGalactic/Аналитика/civilizations_appearance_table.md`.

## ⛔ КРИТИЧЕСКИЕ ПРАВИЛА (нарушение = переделка)

1. **СТРОГО ПО ШАБЛОНУ И ЭТАЛОНУ.** Каждая карта генерируется ТОЛЬКО по шаблону промпта из этого файла и по эталонной карте **Фидан** (`DariaGalactic/Профайлы клиентов/Купившие разбор/Fidan_Verdiyeva_ed994782df4f_20260518/Generated_image.png`). Это ГЛАВНЫЙ эталон. `reference_natalya.png` — вспомогательный стиль-референс. Запрещено генерировать свободную композицию, абстрактный постер, коллаж или любой другой формат, не совпадающий с эталоном Фидан. Все элементы обязательны и располагаются строго как у Фидан:
   - Левая колонка: «ТВОЙ ЗВЁЗДНЫЙ КОД» — 3 портрета с подписями «ЦИВИЛИЗАЦИЯ (ЗВЕЗДА)»
   - Центр верх: «СИМВОЛ ТВОЕЙ СУТИ» — крупный сакральный тотем (Асцендент + доминирующая цивилизация)
   - Центр: формула из 3 глаголов → ИМЯ КЛИЕНТА крупно
   - Центр низ: 3 медальона сакральной геометрии из `sacred_geometry_table.md` с подписями «ЗВЕЗДА / ПРИНЦИП»
   - Лево низ: «ЕЖЕДНЕВНАЯ ПРАКТИКА» (3 пункта с иконками полумесяца)
   - Право верх: «СВЕТ И ТЕНЬ» (два столбца)
   - Право: «ШКАЛА МИССИИ» — СТУПЕНЧАТАЯ ЛЕСТНИЦА (блоки 20%/50%/100%)
   - Право: «ЭФИРНЫЕ МАСЛА» — 3 капли
   - Право: «КАМНИ И МАТЕРИАЛЫ» — 3 камня
   - Право низ: «СИМВОЛ ДЛЯ ПРОХОЖДЕНИЯ МИССИИ» — сакральный символ + 2 слова-ключа
   Отклонение от шаблона = переделка.
2. **НЕ монохром.** Три цветовых семейства по цивилизациям клиента, равномерно по всей карте. Вся карта в одном цвете = переделка.
3. **Цветок Жизни — ЧЁТКИЙ контур.** Геометрически точный, не размытый. Размытый = переделка.
4. **Птичьи/звериные цивилизации** (Орёл, Лев и др.) — ВЫРАЖЕННЫЕ нечеловеческие черты (перья, крылья, клюв, грива). Не просто человек с символикой.
5. **Под именем клиента — НИЧЕГО.** Имя = финальный элемент центра. Без повторов из шкалы миссии.
6. **Все треугольники — только вершиной вверх.**
7. **Сакральные символы — ТОЛЬКО из `sacred_geometry_table.md`.** Каждый медальон внизу = конкретная звезда из карты клиента + её символ из таблицы. Не выдумывать символы.
8. **reference_image_paths — ВСЕГДА передавать картинку Фидан** как основной эталон вместе с `reference_natalya.png`.

## Алгоритм (пошагово)

### Шаг 1. Прочитай анализ миссии клиента

Из `<Имя>_<DDMMYYYY>_миссия.md` возьми:
- Имя клиента
- Топ-3 (или топ-4) цивилизации
- Доминирующую цивилизацию
- Ключевые способности, тени, практики
- Асцендент, накшатру, её символ
- Галактические точки (если есть)

### Шаг 2. Прочитай summary клиента

Из `summary.md` возьми:
- `civilization:` — доминирующая цивилизация
- `headline:` — формулировка сути
- «Ваш дар» — ключевые способности
- «Ваш вызов» — тени
- «Что делать» — практики (для блока «ЕЖЕДНЕВНАЯ ПРАКТИКА»)

### Шаг 3. Найди референсы созвездий

Порядок приоритета строгий:

1. **Референс Дарьи:** `_референсы_созвездий/<key>_ref.png`
2. **Открытый каталог:** `_референсы_созвездий/open_catalog/<key>/reference.png`
3. **Нет ни того, ни другого** — не генерируй картинку, напиши какого созвездия не хватает

Доступные референсы от Дарьи: `scorpius`, `centaurus`, `orion`, `lyra`, `draco`, `andromeda`, `cetus`, `canis_major`, `canis_minor`.

По найденному референсу подготовь чистую trace-схему (точки + линии, без фото-фона):
```
D:\DariaGalactic\Профайлы клиентов\<папка_клиента>\constellation_refs\<key>_trace.png
```

### Шаг 4. Прочитай внешность цивилизаций

Если в левой колонке показываются представители цивилизаций (а не созвездия), прочитай `DariaGalactic/Аналитика/civilizations_appearance_table.md` и выпиши визуальные признаки нужных цивилизаций. Для промпта используй строку «Промпт для генерации» из таблицы.

### Шаг 5. Собери данные для промпта

1. **Имя клиента**
2. **3 цивилизации** — название, ключевой смысл, визуальные образы, цвета
3. **Асцендент** — знак, накшатра, символ
4. **Центральный символ** — какие элементы трёх цивилизаций и Асцендента соединить в мандалу
5. **Формула из 3 глаголов** — из раздела «Что делать»
6. **Шкала миссии** — три уровня (20% / 50% / 100%):
   - 20% — начальное пробуждение
   - 50% — активное проявление
   - 100% — полная реализация миссии
7. **Палитра** — 3-4 цвета по цивилизациям (см. таблицу цветовых ассоциаций)
8. **Камни / материалы** — 2-3 шт по цивилизациям
9. **Эфирные масла** — 3 шт, подобранные по смыслу цивилизаций (трансформация/глубина, гармония/красота, путь/исцеление)
10. **Сакральные символы** — из `sacred_geometry_table.md` по Раху, точным аспектам (<0.2°) или галактическим точкам
11. **Свет и Тень** — 4+4 пункта из разбора
12. **Ежедневная практика** — 3 конкретных действия (утро/день/вечер)

### Шаг 6. Генерируй изображение

Вызови `GenerateImage` с промптом из секции «Шаблон промпта» + приложи найденные trace-схемы и эталонную карту как `reference_image_paths`.

### Шаг 7. Проверь и при необходимости наложи созвездия

После генерации проверь левую колонку:
- Если созвездия совпадают с trace-схемами — оставить
- Если искажены — не перегенерировать всю карту, наложить точную trace-схему поверх готовой картинки
- Художественный образ рядом можно оставить, если не мешает схеме

### Шаг 8. Сохрани результат

Финальное изображение → `Generated_image.png` в папке клиента.

## Обязательные элементы изображения

## Обязательная структура правой колонки

- **Правый верх — «СВЕТ И ТЕНЬ»**: 4 пункта «Свет» + 4 пункта «Тень» из разбора.
- **Правая середина** — шкала миссии (с процентами 20/50/100), эфирные масла (3 капли), камни (2-3 шт).
- **Правый низ — «СИМВОЛ ДЛЯ ПРОХОЖДЕНИЯ МИССИИ»**: сакральный символ ОТЛИЧНЫЙ от центральной мандалы. Из `sacred_geometry_table.md` по Раху, точным аспектам (<0.2°) или галактическим точкам. Символ = **чистая сакральная геометрия**, без фигуративных элементов. Под символом — 1 слово-напутствие.

## Пол представителей цивилизаций

- **Для женщин** — портреты представителей в левой колонке **женские**.
- **Для мужчин** — **мужские**.
- Пол определяется по имени клиента и контексту разбора. Не смешивать.

## Эталонная карта — НАТАЛЬЯ 10.11.1996

**Главный эталон:** `.cursor/skills/4-image/reference_natalya.png`

Все новые карты генерируются по этому образцу. Ключевые признаки:
- Левая колонка: 3 женских портрета цивилизаций (Скорпион, Орёл с птичьими чертами, Лира), подписи под каждым
- Центр: мандала с крыльями + символами на фоне ЧЁТКОГО Цветка Жизни
- Под мандалой: формула из 3 глаголов (`ВИДЕТЬ → ПОДНИМАТЬСЯ → ВОПЛОЩАТЬ`)
- Под формулой: ТОЛЬКО имя клиента крупно
- Правая колонка: Свет и Тень → Шкала миссии (20/50/100%) → Масла → Камни → Символ миссии (чистая геометрия)
- Левый низ: «ЕЖЕДНЕВНАЯ ПРАКТИКА» — 3 действия
- Нижний центр: 3 сакральных глифа
- Цвета: три семейства по цивилизациям, не монохром
- Тёмный космический фон, золотые акценты

Использовать как **style-reference**: прикладывать путь к файлу как `reference_image_paths`.

## Запреты

- Не рисовать созвездия по памяти генератора — только из референса
- Не заменять одно созвездие другим (Дракон ≠ Орёл, Большой Пёс ≠ волк, Лира ≠ произвольный музыкальный знак)
- Если в карте показан представитель Большого Пса / Сириуса, не делать его волком или обычным тёмным гуманоидом — сверять с `civilizations_appearance_table.md`
- Не вставлять фото референса в карту, если можно сделать чистую схему
- Не делать квадратных вставок поверх готовой карты
- Не повторять снизу те же картинки, что слева (внизу — сакральные символы)
- **НИКОГДА не рисовать перевёрнутый треугольник** — все треугольники ТОЛЬКО вершиной вверх
- Не добавлять лишние цивилизации, символы и сущности, которых нет в разборе
- Не выходить в интернет за референсами без отдельного разрешения Дарьи
- Не оставлять неудачные промежуточные картинки как финал
- Не придумывай третью цивилизацию, если в разборе только топ-2 (можно добавить `Земной ключ`/Асцендент как панель, но не называть цивилизацией)
- Не использовать шаблонные слова на шкале миссии — только конкретные из анализа этого клиента
- Не искажать имя клиента (кириллица)

## Обязательный self-check после генерации

После каждой генерации проверить по чек-листу:

- [ ] 3+ цветовых семейства (не монохром)
- [ ] Цветок Жизни — чёткий, геометрически точный
- [ ] Левая колонка: портреты представителей (не созвездия), пол соответствует клиенту
- [ ] Все треугольники указывают ТОЛЬКО вверх
- [ ] Есть блок «ЕЖЕДНЕВНАЯ ПРАКТИКА» (левый низ) с 3 действиями
- [ ] Имя клиента написано корректно (кириллица, без искажений)
- [ ] Под именем клиента нет лишних слов
- [ ] Шкала миссии: уникальные слова + проценты 20/50/100, порядок СНИЗУ ВВЕРХ (20 внизу, 100 вверху)
- [ ] Нижний центр: сакральные глифы (не повтор портретов слева)
- [ ] Правый низ: символ миссии = чистая геометрия (без фигур)
- [ ] Точность созвездий ≥90% (если показаны созвездия, а не портреты)

При fail self-check: перегенерировать (до 3 попыток). Если все 3 fail → эскалация Дарье.
