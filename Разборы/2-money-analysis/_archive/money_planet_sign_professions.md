# Справочник: планета + знак → профессиональный архетип и профессии

> **🗄️ В АРХИВЕ с 19.06.2026.** Знак убран из обязательного алгоритма подбора профессий (малоинформативен, редко попадает в цель). Новый алгоритм: накшатра → звезда (при соединении) → дом. Источник профессий — `professions_master.json` + скрипт `.cursor/tools/calc_professions.py`. Этот файл НЕ удалён — может пригодиться как дополнительный справочник, но в основной поток не входит.

Используется агентом при написании разбора ДНК денег. Когда у планеты нет соединения с цивилизацией — профессии выводятся из этой матрицы (планета × знак × дом).

**Приоритет:** дом определяет СФЕРУ дохода (см. таблицу домов в SKILL.md), знак определяет СТИЛЬ и ФОРМАТ, планета определяет КАЧЕСТВО действия. Все три слоя накладываются.

## РАХУ (амбиция, новое, непривычное)

Раху не имеет своего знака. Его профессиональный смысл определяется через:
1. Дом, в котором стоит (куда тянет — новая территория)
2. Знак дома (стиль освоения нового)
3. Диспозитор (планета-управитель знака) — ключ к материализации амбиций

Общий принцип: Раху в доме = «идти туда, где раньше не был, осваивать НОВЫЙ для себя формат дохода через тематику этого дома».

## КЕТУ (врождённый талант, прошлые жизни)

Кету — освоенное прошлое. Профессиональный смысл:
1. Дом Кету = врождённый талант (что умеет «с рождения», не учась)
2. Знак = стиль таланта
3. Диспозитор = канал монетизации (через дом диспозитора)
4. Цивилизация (если есть ☌) = глубинный дар

Общий принцип: Кету в 8-м = врождённая способность работать с чужими кризисами, ресурсами, смертью/перерождением. В 6-м = врождённое умение решать чужие проблемы, целительство. В 12-м = заграница, духовные практики, работа с бессознательным.

## ПРАВИЛО ИСПОЛЬЗОВАНИЯ

1. Найти планету в таблице по её знаку → получить архетип и список профессий
2. Наложить на ДОМ (таблица домов в SKILL.md) → отфильтровать профессии, которые подходят к дому
3. Наложить НАКШАТРУ → уточнить стиль и специфику
4. Если есть ☌ с цивилизацией → цивилизация ПРИОРИТЕТНЕЕ таблицы, но таблица дополняет
5. Результат = 3–5 конкретных профессий, уникальных для этой комбинации

**Пример:** Юпитер (Рыбы, свой знак) в 6-м доме → из таблицы: «целитель-расширитель: психолог, целитель, специалист по энергиям, терапевт». Из дома: «6-й = ежедневный труд, сервис, решение чужих проблем». Результат: «психолог-практик с регулярным приёмом, целитель, специалист по энергиям и психосоматике, реабилитолог — доход через регулярный сервис, к которому возвращаются».
