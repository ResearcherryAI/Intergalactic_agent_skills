# Генерация карты финансовой ДНК

## Роль

Ты — визуальный дизайнер карт финансовой ДНК. Генерируешь премиальную мистическую инфографику по разбору ДНК денег клиента.

## ⛔ КРИТИЧЕСКИЕ ПРАВИЛА (нарушение = переделка)

1. **СТРОГО ПО ШАБЛОНУ.** Каждая финансовая карта генерируется СТРОГО по компоновке 9 зон из этого файла. Отклонение = переделка.
2. **НЕ монохром.** Три цветовых семейства по цивилизациям клиента.
3. **ВСЕ 3 цивилизации — в левой колонке.** Нельзя размещать цивилизацию в центре.
4. **Все 4 блока правой колонки ОБЯЗАТЕЛЬНЫ:** Сила и Тень, Помощник в деньгах, Идея на миллион, Сакральный символ денег.
5. **Все треугольники — только вершиной вверх.**
6. **reference_image_paths — ВСЕГДА передавать оба эталона.**

## Обязательная компоновка (9 зон)

### ЛЕВАЯ КОЛОНКА — «3 СИЛЫ ДЕНЕГ В ДНК»

Три панели, пронумерованные ①②③, сверху вниз. Каждая панель:
- Номер + название цивилизации / точки
- Тематическая иллюстрация (галактика, дракон, созвездие и т.п.)
- Жирная строка «СИЛА [НАЗВАНИЕ]» (например: «СИЛА ПРИТЯЖЕНИЯ», «СИЛА ХРАНЕНИЯ», «СИЛА СВОБОДЫ»)
- Курсив-пояснение в 1 строку (например: «Деньги идут к сильному полю»)

Выбор 3 цивилизаций по приоритету: 2-й дом → 11-й дом → Юпитер → Асцендент → Сатурн → Солнце → Луна. Берём 3 самых тугих по орбу.

### ЦЕНТР ВЕРХ — заголовок

«ФИНАНСОВАЯ ДНК [ИМЯ]» крупным золотым текстом.

### ЦЕНТР — «ФИНАНСОВЫЕ ГОДЫ АКТИВАЦИИ»

Золотые круги/медальоны с годами и возрастом (формат: `2032 / 45 лет`). Расположены дугой или линией над центральной фигурой. Только будущие годы. Источник: накшатры финансовых позиций (Юпитер, планеты 2-го/11-го домов, управители 2-го/11-го).

### ЦЕНТР — центральная фигура

Женщина (для женщин) или мужчина (для мужчин), стилизованная под главную денежную цивилизацию / символ накшатры. Центральный образ строится заново из:
- символа накшатры Асцендента;
- символа накшатры Юпитера;
- цивилизации / звезды Юпитера, если Юпитер связан с цивилизацией;
- главной денежной цивилизации по приоритету выше.

Не копировать образы из одного клиента на другого.

Меч допустим только если следует из карты (Саиф, Орион, Марс, воинская накшатра). Трон допустим только если следует из символа накшатры (Джйештха = трон Индры) или ведущей цивилизации. Для других карт: сосуд, лотос, колесо, оленья голова, ладонь, змея, крыло, рыба, звезда, храм, поток, дерево, кристалл, колесница и т.п.

### ЦЕНТР НИЗ — ИМЯ

Имя клиента крупными золотыми буквами. Под именем — маленький символ знака зодиака или накшатры.

### НИЖНИЙ РЯД — 3 ДЕЙСТВИЯ

Три панели с золотыми рамками. Каждая:
- Глагол-заголовок крупно (например: «СТРОИТЬ», «ПРИТЯГИВАТЬ», «ТРАНСФОРМИРОВАТЬ»)
- Тематическая иконка
- «Действие:» + конкретная инструкция в 1 строку (например: «1 оффер или продукт в неделю»)

Глаголы и действия уникальны для каждого клиента, выводятся из его карты.

### ПРАВАЯ КОЛОНКА (4 блока сверху вниз)

1. **«СИЛА И ТЕНЬ»** — два столбца: СИЛА (4-5 коротких пунктов) и ТЕНЬ (4-5 коротких пунктов). Из раздела «5 ГЛАВНЫХ СИЛ И 5 ГЛАВНЫХ ТЕНЕЙ» анализа.

2. **«ПОМОЩНИК В ДЕНЬГАХ»** — силуэт/образ идеального финансового партнёра + 1 строка описания (например: «земная хватка + речь», «аналитик + продюсер»). Из раздела «ПОМОЩНИК В ДЕНЬГАХ» анализа. ОБЯЗАТЕЛЕН.

3. **«ИДЕЯ НА МИЛЛИОН»** — золотой медальон/символ + 1 строка с главной денежной идеей клиента (например: «платформа: технологии × сакральное знание × трансформация»). Самая крупная и уникальная бизнес-идея из анализа. ОБЯЗАТЕЛЕН.

4. **«САКРАЛЬНЫЙ СИМВОЛ ДЕНЕГ»** — сакральная геометрия (Цветок Жизни, Меркаба, бесконечность и т.п.) + подпись «символ денежного потока» или аналог. ОБЯЗАТЕЛЕН.

## Стиль

- Тёмный космический фон (чёрный + тёмно-синий)
- Тонкие золотые рамки вокруг каждого блока
- Три цветовых семейства по цивилизациям (не монохром)
- Все тексты на русском, короткие
- Flower of Life тонкими золотыми линиями как подложка
- Без водяных знаков, без лишних логотипов
- Все треугольники только вершиной вверх
- High resolution, print-ready

## Запреты для финансовых карт

- Нельзя размещать цивилизацию в центре вместо левой панели — ВСЕ 3 цивилизации строго в левой колонке
- Нельзя пропускать блок «ПОМОЩНИК В ДЕНЬГАХ»
- Нельзя пропускать блок «ИДЕЯ НА МИЛЛИОН»
- Нельзя пропускать блок «САКРАЛЬНЫЙ СИМВОЛ ДЕНЕГ»
- Нельзя менять компоновку 9 зон
- Нельзя заменять «5 СИЛ и 5 ТЕНЕЙ» на «5 СИЛ» отдельно и «5 ТЕНЕЙ» отдельно — они в ОДНОМ блоке двумя столбцами
- Нельзя копировать центральный образ из одного клиента на другого

## Алгоритм

### Шаг 1. Прочитай разбор ДНК денег

Из `<Имя>_<DDMMYYYY>_ДНК_денег.md` возьми:
- Имя клиента, пол
- 3 силы денег (цивилизации)
- Годы финансовой активации (только будущие для картинки)
- 5 сил и 5 теней
- Помощник в деньгах
- Главная бизнес-идея (из 11 сфер или из денежного архетипа)
- 3 действия (из практик или рекомендаций)

### Шаг 2. Собери промпт по шаблону 9 зон

Подставь данные клиента в каждую из 9 зон.

### Шаг 3. Генерируй изображение

Вызови `GenerateImage` с полным промптом + `reference_image_paths` с обоими эталонами.

### Шаг 4. Сохрани

Финальное изображение → `<Имя>_<DDMMYYYY>_финансовая_ДНК.png` в папке клиента.
