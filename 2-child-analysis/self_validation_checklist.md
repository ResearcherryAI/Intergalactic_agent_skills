# Чек-лист самовалидации детского разбора (HARD RULE)

**Установлено Дарьёй 14.08.2026.**

Агент ОБЯЗАН пройти КАЖДЫЙ пункт перед тем как показать разбор Дарье. Если хоть один пункт не пройден — переписать. Без прохождения чек-листа показывать текст ЗАПРЕЩЕНО.

---

## A. СТРУКТУРА

| ✓ | Проверка |
|---|----------|
| ☐ | **Соединения посчитаны.** Число строк «Соединение» из CSV указано во вступлении. 10+ = «очень старая душа», 5–9 = «старая душа», <5 = не писать. |
| ☐ | **Топ-3: один заголовок = одна цивилизация.** Нигде нет «+» между созвездиями в заголовке. |
| ☐ | **Топ-3: TIER детский.** Планеты тела (ASC, Луна, Солнце, лагнеша, хоз. 4-го) ☌≤1° = вес 3; внутренние ☌≤1° = вес 2; внешние ☌≤2° = вес 2, >2–5° = вес 1. При равном весе побеждает меньший орб. |
| ☐ | **Планеты в 1-м доме описаны на уровне ASC.** Любая планета, стоящая в 1-м доме, раскрывается так же подробно, как хозяин 4-го в разделе матери и хозяин 9-го в разделе отца: соединения, накшатра, что даёт ребёнку телесно и характерно. |
| ☐ | **Мать (Луна / хоз. 4-го / 4-й дом) — развёрнуто.** Мама себя узнает. Есть: соединения + накшатра + цивилизация в 4-м (если есть) + «какая она» + «чему матери учиться». |
| ☐ | **Отец (Солнце / хоз. 9-го / 9-й дом) — развёрнуто.** Папа себя узнает. Тот же уровень подробности. |
| ☐ | **Раху/Кету — живая проза.** Нет стрелки «→». Есть: дом, знак, накшатра, управители, тень, мост. |
| ☐ | **CTA курса = боль → решение.** Не перечисление модулей. 5 предложений. Боль: «зависеть от чужого разбора». Решение: «научиться самому». |

## B. КАЧЕСТВО ТЕКСТА

| ✓ | Проверка |
|---|----------|
| ☐ | **Ctrl+F каждой планеты** — ни одна не описана дважды в разных разделах. Если раскрыта в одном месте — в другом НЕ повторять. |
| ☐ | **Нет «описываем через накшатру»**, «нет соединения» как финального текста. Формула: «набирает опыт земной жизни через [накшатру], [знак], [дом]» — или полная раскладка. |
| ☐ | **Нептун/Уран без звезды** — написано конкретно (мечты, идеалы, что одурманивает / что срывает, нетерпимость), НЕ «набирает опыт». |
| ☐ | **Кету = уже набранный / устоявшийся опыт рода**, не «набирает». |
| ☐ | **Дома многомерные.** 2-й = деньги + еда + голос + ценности + внешность. 4-й = сердце / грудь / эмоциональный климат (НЕ желудок). 5-й = творчество + игра + романтика + удовольствие. 8-й = кризисы + чужие ресурсы + страхи + потери. 11-й = друзья + общие цели + мечты + признание в группе. 12-й = сон + подсознание + потери + что забирает энергию. |
| ☐ | **Трактовки домов — из источников.** Шпаргалки `07`/`07a`/`07b`/`07c`, `library_compact.json`, книга «Активация». Не из головы. |
| ☐ | **Здоровье из шпаргалки 07a (Лагна) + 08_Накшатры_здоровье (накшатры планет).** Не придумано «на глаз». |
| ☐ | **Тест «подставь другое имя»** — если «Что нельзя» / «Что делать» работает без правок для другого ребёнка → FAIL, переписать. Каждая рекомендация привязана к конкретной планете/звезде/дому ЭТОГО ребёнка. |
| ☐ | **Спорт / кружки уникальны** — связаны с Марсом (знак, дом, накшатра), цивилизациями топ-3. ≤2 совпадения с последним разбором. |
| ☐ | **Нет служебного текста** в файле клиента: «(на картинку)», «уже описано в топ-3», «описываем через…», мета-пометки. |
| ☐ | **Ясность**: каждое предложение понятно родителю без астрологического образования. Нет «водный код», «огненная энергия», «лунная поддержка» без расшифровки. |
| ☐ | **3-й и 11-й дом: братья/сёстры — условно.** Не утверждать что они есть. Писать: «если есть братья/сёстры — отношения будут такими-то, обратить внимание на…». Формулировка условная. Утверждение «у него есть братья» без данных = FAIL. |
| ☐ | **Оппозиция ≠ готовое качество.** Любой аспект кроме ☌ описан как задача / урок / зеркало, а не как данность и не как «его ДНК». |

## C. КАРТИНКА

| ✓ | Проверка |
|---|----------|
| ☐ | **Родители развёрнуты к ребёнку**, смотрят на него/неё с теплом. Голова вниз / в сторону = переделка. |
| ☐ | **Вихрь / спираль в груди ребёнка** — энергии от обоих родителей сходятся в видимый плотный узел. |
| ☐ | **ДНК-подпись ТОЛЬКО на ☌ со звездой.** Оппозиция / трин / секстиль / квадрат = нет подписи. Нет соединения = нет подписи. ИСКЛЮЧЕНИЙ НЕТ. |
| ☐ | **Брендинг:** «ИСТОК — Карта детского потенциала» + «Метод: Межгалактическая астрология» + «Автор метода: КАЙЯ КАЭН». |
| ☐ | **Семьи рас** в кругах (взрослый + ребёнок одной расы в их мире), не одиночки. |
| ☐ | **Нет созвездий** (стик-фигур, зодиакальных пиктограмм). |
| ☐ | **Этничность по семье**, не по городу рождения. Если семья русская — славянские черты. |
| ☐ | **Яркие насыщенные цвета**, ultra-sharp focus. Пастельные / мыльные / размытые = переделка. |

## Порядок применения

1. Написать MD-текст.
2. Пройти ВСЕ пункты A + B. Отметить каждый.
3. Если хоть один FAIL — исправить и пройти заново.
4. Только после PASS всех пунктов — показать Дарье.
5. После «ок» на текст — генерировать картинку, пройти блок C.
6. После PASS блока C — показать Дарье.

**Без полного прохождения чек-листа показывать текст или картинку = нарушение жёсткого правила.**
